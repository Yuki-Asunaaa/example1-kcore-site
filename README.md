# 例题一：k-核分解可视化

公开网页：https://yuki-asunaaa.github.io/example1-kcore-site/

这是用于 GitHub Pages 的静态发布副本，包含前端交互、D3 和十个匿名编号节点的计算结果。网页支持 k 核分组、节点详情、剥离步骤回放和 JSON 下载。

GitHub Pages 不运行 Python；此处使用项目生成的静态 `graph.json`。完整 Python 手写算法、源矩阵和测试保留在私有的 `example1-kcore` 仓库中。修改网页请更新此仓库；更新计算结果需在私有源项目重新导出 `output/graph.json`，复制至此仓库 `graph.json` 后提交。
